Интернет магазин мебели

Много страничный сайт с примерами товаров, свёрстаный по методологии БЭМ и с функцией взоимодействия фильтрации.

Посмотреть сайт
    Этот проект демонстрирует уверенные навыки статической верстки.
  • HTML5 и семантическая верстка: Использование тегов "article", "h3", "p" для структурирования карточек товаров.
  • CSS3 и Flexbox/Grid: Создание сетки каталога (вероятно, с помощью display: grid или flex), чтобы карточки красиво располагались в несколько колонок.
  • Методология БЭМ: Названия классов вроде product-card, product-card__title, product-card__price (если вы использовали БЭМ, о чем писали в профиле). Это делает код читаемым и масштабируемым.
  • Стилизация текста и изображений: Настройка типографики (шрифты, размеры, отступы) и работа с изображениями товаров.
  • Адаптивность: Верстка, которая корректно отображается на разных устройствах (мобильные, планшеты, десктопы).

Сайт мини-игр

Интерактивный сайт с шестью играми на JavaScript.

Посмотреть
    Этот проект — отличная демонстрация навыков программирования на JavaScript.
  • JavaScript (ES6+): Написание логики для шести различных игр.
  • Работа с DOM: Динамическое изменение содержимого страницы (например, вывод вопросов викторины, генерация случайных чисел, изменение текста).
  • Обработка событий: Использование addEventListener для отслеживания кликов по кнопкам и ввода текста пользователем.
  • Управление состоянием: Отслеживание счета в играх, текущего вопроса, попыток угадать число.
  • Математические операции и работа со строками: Генерация случайных чисел (Math.random()), переворот текста (split().reverse().join()), простые арифметические вычисления.
  • Создание интерактивного UI: Кнопки, поля ввода и модальные окна, которые реагируют на действия пользователя.

Проект "Коментарии"

Страница с комментариями, демонстрирующая работу с DOM.

Посмотреть
    Этот проект сфокусирован на работе с динамическим контентом.
  • Работа с DOM (Document Object Model): Это ключевой навык. Вы демонстрируете умение создавать новые элементы (document.createElement), добавлять их на страницу (appendChild), изменять их свойства и содержимое.
  • Шаблонизация и рендеринг: Вероятно, вы создавали HTML-структуру для нового комментария (имя, дата, текст) и вставляли её в список.
  • Обработка форм: Добавление новых комментариев, скорее всего, происходит через форму. Это навык получения данных из полей ввода и их валидации.
  • Работа с датами: Форматирование и вывод текущей даты и времени для нового комментария.
